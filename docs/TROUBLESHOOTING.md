# Диагностика проблем с воркерами

## Проблема: Проверяется только один товар из нескольких

### Диагностика

1. **Проверьте состояние треков в БД:**
   ```bash
   npm run debug:tracks
   ```

2. **Проверьте состояние очередей:**
   ```bash
   npm run debug:queues
   ```

3. **Проверьте логи воркера:**
   ```bash
   docker-compose logs price-checker
   ```

### Возможные причины

1. **Отсутствуют повторяющиеся задачи в Redis**
   - Задачи могли быть потеряны при перезагрузке
   - Проблема с созданием задач при добавлении товаров

2. **Неправильные интервалы проверки**
   - Слишком большие интервалы (например, 6 часов)
   - Неправильный формат cron-выражений

3. **Проблемы с воркером**
   - Воркер не запущен
   - Ошибки в обработке задач
   - Проблемы с подключением к БД/Redis

### Решение

1. **Восстановите повторяющиеся задачи:**
   ```bash
   npm run restore:jobs
   ```

2. **Перезапустите воркеры:**
   ```bash
   docker-compose restart price-checker notifier
   ```

3. **Проверьте конфигурацию интервалов:**
   - В `.env` файле: `DEFAULT_CHECK_INTERVAL_HOURS=0.0833333` (5 минут)
   - Для Pro: `PRO_CHECK_INTERVAL_HOURS=0.0833333` (5 минут)

### Мониторинг

1. **API статистика:**
   ```bash
   curl http://localhost:3000/api/stats
   ```

2. **Grafana дашборд:**
   - Откройте http://localhost:3001
   - Логин: admin
   - Пароль: из переменной `GF_SECURITY_ADMIN_PASSWORD`

### Профилактика

1. **Регулярно проверяйте логи:**
   ```bash
   docker-compose logs --tail=100 price-checker
   ```

2. **Мониторьте метрики:**
   - Количество активных треков
   - Количество повторяющихся задач
   - Частота проверок цен

3. **Настройте алерты в Grafana** для критических метрик

## Частые проблемы

### Воркер не запускается
```bash
# Проверьте статус контейнеров
docker-compose ps

# Проверьте логи
docker-compose logs price-checker
```

### Задачи не обрабатываются
```bash
# Проверьте подключение к Redis
docker-compose exec redis redis-cli ping

# Проверьте подключение к PostgreSQL
docker-compose exec postgres pg_isready -U price_watcher
```

### Повторяющиеся задачи не создаются
```bash
# Проверьте права доступа к Redis
docker-compose exec redis redis-cli info keyspace

# Восстановите задачи вручную
npm run restore:jobs
```
