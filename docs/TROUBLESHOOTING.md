# Устранение неполадок

## Проблемы с мониторингом

### Воркеры не отслеживаются в мониторинге

**Симптомы:**
- В Grafana не отображаются метрики воркеров
- Логи воркеров не попадают в основной поток логирования
- Дашборд "Price Watcher - Воркеры и очереди" показывает пустые данные

**Причины:**
1. Воркеры запускаются как отдельные процессы и не интегрированы с основным приложением
2. Отсутствует импорт воркеров в основном файле приложения
3. Не настроены метрики для отслеживания состояния воркеров

**Решение:**

1. **Интеграция воркеров в основное приложение:**
   ```typescript
   // В src/index.ts добавлены импорты:
   import "./workers/price-checker";
   import "./workers/notifier";
   ```

2. **Добавлены новые метрики для воркеров:**
   - `price_watcher_worker_health` - состояние здоровья воркеров
   - `price_watcher_worker_uptime_seconds` - время работы воркеров
   - `price_watcher_worker_memory_bytes` - использование памяти

3. **Улучшено логирование воркеров:**
   - Периодические health checks каждые 5 минут
   - Детальная информация о состоянии очередей
   - Метрики использования памяти и времени работы

4. **Обновлен дашборд Grafana:**
   - Добавлены панели для мониторинга здоровья воркеров
   - Графики использования памяти
   - Время работы воркеров

**Проверка решения:**

1. Запустите приложение:
   ```bash
   npm run dev
   ```

2. Проверьте состояние воркеров:
   ```bash
   npm run debug:workers
   ```

3. Откройте Grafana и проверьте дашборд "Price Watcher - Воркеры и очереди"

4. Проверьте метрики:
   ```bash
   curl http://localhost:3000/metrics | grep worker
   ```

**Дополнительные команды для отладки:**

- `npm run debug:queues` - проверка состояния очередей
- `npm run debug:tracks` - проверка отслеживаний
- `npm run debug:workers` - проверка состояния воркеров

### Воркеры не запускаются

**Симптомы:**
- Ошибки подключения к Redis
- Задачи накапливаются в очереди, но не обрабатываются
- Логи показывают ошибки инициализации воркеров

**Решение:**

1. Проверьте подключение к Redis:
   ```bash
   redis-cli ping
   ```

2. Проверьте переменные окружения:
   ```bash
   cat .env | grep REDIS
   ```

3. Перезапустите воркеры:
   ```bash
   # Остановите приложение
   # Запустите заново
   npm run dev
   ```

### Метрики не обновляются

**Симптомы:**
- Prometheus не получает новые метрики
- Grafana показывает устаревшие данные
- Метрики воркеров остаются на нуле

**Решение:**

1. Проверьте endpoint метрик:
   ```bash
   curl http://localhost:3000/metrics
   ```

2. Проверьте конфигурацию Prometheus:
   ```yaml
   # monitoring/prometheus.yml
   scrape_configs:
     - job_name: "price-watcher"
       static_configs:
         - targets: ["app:3000"]
       metrics_path: "/metrics"
       scrape_interval: 30s
   ```

3. Перезапустите мониторинг:
   ```bash
   npm run monitoring:start
   ```


2. **Мониторьте состояние очередей:**
   ```bash
   npm run debug:workers
   ```

3. **Проверяйте метрики в реальном времени:**
   - Откройте Grafana: http://localhost:3001
   - Проверьте дашборд "Price Watcher - Воркеры и очереди"

4. **Настройте алерты:**
   - Создайте алерты в Grafana для критических метрик
   - Настройте уведомления при падении воркеров

## Частые проблемы

### Воркер не запускается
```bash
# Проверьте статус контейнеров
docker-compose ps

# Проверьте логи
docker-compose logs price-checker
```

### Задачи не обрабатываются
```bash
# Проверьте подключение к Redis
docker-compose exec redis redis-cli ping

# Проверьте подключение к PostgreSQL
docker-compose exec postgres pg_isready -U price_watcher
```

### Повторяющиеся задачи не создаются
```bash
# Проверьте права доступа к Redis
docker-compose exec redis redis-cli info keyspace

# Восстановите задачи вручную
npm run restore:jobs
```
