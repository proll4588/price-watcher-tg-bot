# Система аналитики и мониторинга

## Обзор

В приложении реализована комплексная система аналитики и мониторинга с использованием Prometheus и Grafana. Система отслеживает ключевые метрики производительности, пользовательской активности и работы воркеров.

## Архитектура

### Компоненты

1. **MetricsService** (`src/services/metrics.ts`) - основной сервис для управления метриками Prometheus
2. **AnalyticsService** (`src/services/analytics.ts`) - сервис для периодического обновления метрик из БД
3. **Grafana Dashboards** - готовые дашборды для визуализации метрик
4. **Prometheus** - система сбора и хранения метрик

### Метрики

#### Пользователи
- `price_watcher_new_users_total` - общее количество новых пользователей
- `price_watcher_active_users` - количество активных пользователей
- `price_watcher_total_users` - общее количество пользователей

#### Отслеживания
- `price_watcher_track_requests_total` - запросы на отслеживание товаров
- `price_watcher_active_tracks` - активные отслеживания
- `price_watcher_total_tracks` - общее количество отслеживаний
- `price_watcher_track_removals_total` - удаления отслеживаний

#### Воркеры
- `price_watcher_price_checks_total` - проверки цен
- `price_watcher_price_check_duration_seconds` - время выполнения проверок цен
- `price_watcher_notifications_sent_total` - отправленные уведомления
- `price_watcher_notifications_failed_total` - неудачные уведомления
- `price_watcher_worker_errors_total` - ошибки воркеров

#### Товары
- `price_watcher_products_tracked` - отслеживаемые товары
- `price_watcher_price_snapshots_total` - снимки цен
- `price_watcher_price_changes_total` - изменения цен

#### Очереди
- `price_watcher_queue_jobs_waiting` - ожидающие задачи
- `price_watcher_queue_jobs_active` - активные задачи
- `price_watcher_queue_jobs_completed` - завершенные задачи
- `price_watcher_queue_jobs_failed` - неудачные задачи

## API Endpoints

### Метрики Prometheus
```
GET /metrics
```
Возвращает метрики в формате Prometheus.

### Системная статистика

## Дашборды Grafana

### 1. Price Watcher - Обзор
**UID:** `price-watcher-overview`

Основной дашборд с ключевыми метриками:
- Общее количество пользователей
- Активные пользователи
- Новые пользователи (в минуту)
- Запросы на отслеживание (в минуту)
- Активные отслеживания
- Проверки цен (в минуту)
- Отправленные уведомления (в минуту)
- 95-й процентиль времени проверки цен

### 2. Price Watcher - Воркеры и очереди
**UID:** `price-watcher-workers`

Мониторинг производительности воркеров:
- Ожидающие задачи в очереди
- Активные задачи в очереди
- Завершенные задачи (в минуту)
- Неудачные задачи (в минуту)
- Ошибки воркеров (в минуту)
- Процент неудачных уведомлений
- Медианное время проверки цен
- 99-й процентиль времени проверки цен

### 3. Price Watcher - Аналитика по провайдерам
**UID:** `price-watcher-providers`

Аналитика по торговым площадкам:
- Активные отслеживания по провайдерам
- Отслеживаемые товары по провайдерам
- Запросы на отслеживание по провайдерам
- Проверки цен по провайдерам
- Снимки цен по провайдерам
- Изменения цен по провайдерам
- 95-й процентиль времени проверки по провайдерам
- Процент неудачных проверок по провайдерам

## Настройка

### 1. Prometheus

Убедитесь, что в `monitoring/prometheus.yml` настроен сбор метрик:

```yaml
scrape_configs:
  - job_name: "price-watcher"
    static_configs:
      - targets: ["app:3000"]
    metrics_path: "/metrics"
    scrape_interval: 30s
```

### 2. Grafana

1. Импортируйте дашборды из папки `monitoring/grafana/dashboards/`
2. Настройте источник данных Prometheus
3. Убедитесь, что UID дашбордов совпадают с указанными выше

### 3. Переменные окружения

Добавьте в `.env`:
```env
# Настройки метрик
METRICS_ENABLED=true
METRICS_UPDATE_INTERVAL=60000
```

## Мониторинг в реальном времени

### Ключевые индикаторы

1. **Пользовательская активность**
   - Рост новых пользователей
   - Конверсия в активных пользователей
   - Удержание пользователей

2. **Производительность системы**
   - Время отклика проверки цен
   - Количество ошибок воркеров
   - Загрузка очередей

3. **Качество данных**
   - Процент неудачных проверок цен
   - Процент неудачных уведомлений
   - Доступность провайдеров

### Алерты

Рекомендуется настроить алерты в Grafana для:
- Высокого процента ошибок (>5%)
- Долгого времени отклика (>30 секунд)
- Большого количества ожидающих задач (>100)
- Резкого падения новых пользователей

## Расширение системы

### Добавление новых метрик

1. Добавьте метрику в `MetricsService`
2. Обновите соответствующий сервис для отправки метрик
3. Добавьте панель в дашборд Grafana

### Создание новых дашбордов

1. Создайте JSON файл в `monitoring/grafana/dashboards/`
2. Используйте существующие метрики или добавьте новые
3. Импортируйте дашборд в Grafana

## Troubleshooting

### Метрики не обновляются
1. Проверьте подключение к Prometheus
2. Убедитесь, что сервис аналитики запущен
3. Проверьте логи на ошибки

### Дашборды не отображают данные
1. Проверьте источник данных Prometheus
2. Убедитесь, что метрики собираются
3. Проверьте временной диапазон

### Высокая нагрузка на систему
1. Увеличьте интервал обновления метрик
2. Оптимизируйте запросы к БД
3. Рассмотрите использование кэширования
