## 🚀 CI/CD Pipeline

```
GitHub → GitHub Actions → Арендованный сервер → VPN → Домашний сервер (Docker)
```

### Этапы деплоя:
1. **Тестирование** - проверка кода, линтинг, тесты
2. **Сборка** - создание Docker образов
3. **Деплой** - обновление на сервере
4. **Миграции** - применение изменений БД
5. **Health Check** - проверка работоспособности
6. **Откат** - автоматический при ошибках

## 📊 Мониторинг

### Компоненты мониторинга:
- **Prometheus** - сбор метрик
- **Grafana** - визуализация данных
- **Health Checks** - проверка здоровья сервисов
- **Логирование** - структурированные логи

### Доступ к мониторингу:
- Prometheus: `http://localhost:9090`
- Grafana: `http://localhost:3001`

## 🔒 Безопасность

### Переменные окружения:
- Все секреты хранятся в `.env` файлах (не в Git)
- GitHub Secrets для CI/CD
- Шифрование чувствительных данных

### Сетевая безопасность:
- VPN между серверами
- SSH ключи для аутентификации
- Ограничение доступа по IP

## 🛠️ Устранение неполадок

### Частые проблемы:

#### Ошибка деплоя
```bash
# Проверьте логи GitHub Actions
# Проверьте логи на сервере
tail -f /var/log/deployments/my-app.log
```

#### Проблемы с базой данных
```bash
# Проверьте подключение
docker-compose exec app npx prisma db push

# Проверьте миграции
docker-compose exec app npx prisma migrate status
```

#### Проблемы с Telegram Bot
```bash
# Проверьте токен
curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getMe"

# Проверьте webhook
curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/getWebhookInfo"
```
